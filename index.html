⌨️ 快捷键与高阶用法
  • Ctrl + K : 唤出全库搜索与命令库
  • Ctrl + S : 强制手动静默保存
  • / : 输入斜杠直接呼出排版菜单
  • Alt + S : 一键发送内容至 Telegram
  • Alt + ↑/↓ : 快捷上下移动当前行
  • Ctrl + B / I : 快速加粗 / 斜体
  • 选中文本按 [, ", ( : 自动成对包裹符号
  • 长按 Alt 0.8秒 : 随时呼出此快捷键面板
  • 标题带 #标签名 : 侧边栏自动按标签折叠归类
  • Ctrl + V 贴图 : 自动高强度压缩并转为纯文本代码

    ☁️ 云端同步与高级设置
    1. WebDAV 私有云同步 (含防覆盖保护)
    配置 WebDAV 服务器，实现多端双向同步。支持自动冲突检测。
    2. Telegram Bot 配置
    按下 Alt + S 快速将选中文本/全文发送到你的 TG。
    3. 自定义代码片段 (Snippets)
    格式：触发词 === 替换文本（每行一个）。输入触发词后自动替换。
    4. 图床配置 (SM.MS) 解决本地存储爆满
    前往 sm.ms 注册获取 API Token。配置后粘贴图片将自动上传图床，不再占用本地空间。
    5. 本地工作区全量备份
    将你的所有文档、设置、快照打包为一个 JSON 文件下载，或从 JSON 文件恢复。
